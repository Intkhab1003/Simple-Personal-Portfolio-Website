# 🌌 Khabii | Personal Portfolio Website

![HTML5](https://img.shields.io/badge/html5-%23E34F26.svg?style=for-the-badge&logo=html5&logoColor=white)
![CSS3](https://img.shields.io/badge/css3-%231572B6.svg?style=for-the-badge&logo=css3&logoColor=white)

A premium, futuristic, and fully responsive personal portfolio website built entirely with **pure HTML5 and CSS3**. 

This project was developed to showcase advanced CSS capabilities—including glassmorphism, 3D transforms, keyframe animations, and a fully functional mobile navigation menu—**without the use of any JavaScript or external CSS frameworks (like Bootstrap or Tailwind)**.



## ✨ Features

*   **Dark Futuristic UI:** A deep near-black background with electric cyan and violet accents.
*   **CSS 3D Transforms:** Project cards feature perspective tilts and layered depth purely through CSS `:hover` states.
*   **Glassmorphism:** Frosted glass panels with subtle glowing borders for an elegant visual hierarchy.
*   **Zero JavaScript:** Everything, including the responsive mobile hamburger menu (using the CSS checkbox hack) and smooth scrolling, is handled directly in CSS.
*   **Fully Responsive:** Fluid layouts using CSS Grid and Flexbox that adapt perfectly to desktop, tablet, and mobile screens.
*   **Accessibility:** Includes semantic HTML5 markup and `prefers-reduced-motion` support for users who disable animations.

## 🛠️ Technologies Used

*   **HTML5:** Semantic structure, inline SVGs for optimized icons, and accessible form design.
*   **CSS3:** Custom variables, CSS Grid/Flexbox, `@keyframes` ambient animations, and media queries.
*   **Google Fonts:** 'Outfit' font family for a sleek, modern aesthetic.
